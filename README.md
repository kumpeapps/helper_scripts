# helper_scripts

Scripts and helpers for Git workflows.

## Contents
- `git_helpers/git-helper.sh`: Menu-driven Git helper (whiptail/dialog/text) with guided flows for add/commit/push, history rewrite/squash/rebase, cleanup, stash, tags, remotes, and utilities. Supports commit message prefix via `GIT_HELPER_PREFIX` (`{{branch}}`, `{{ticket}}`). See [git_helpers/README.md](git_helpers/README.md) for full details.
